# Nightmoon

Soulslike top-down em GameMaker

| Pasta | O que tem |
|---|---|
| `nightmoon/` | o projeto do GameMaker (abra o `nightmoon.yyp`) |
| `docs/` | [GDD](docs/GDD.md),
| `arte/` | a arte pronta pra importar (sprite sheets `.png` e prévias `.gif`), separada por tipo |
| `tools/sprites/` | de onde a arte sai: um módulo Python por sprite (`python tools/sprites/sprites.py exporta` regera `arte/`), os `.aseprite`, a paleta e o perfil de estilo |
| `audio/` | sons originais (`.wav`/`.ogg`) antes de importar no GameMaker |
| `build/` | executáveis gerados no dia 21 (fora do Git) |
